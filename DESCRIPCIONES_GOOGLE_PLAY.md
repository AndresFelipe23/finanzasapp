# Descripciones para Imágenes de Google Play Store
## Financially - Aplicación de Gestión Financiera Personal

---

## 1. INICIO / HOME

**Título:**
```
Vista General de tus Finanzas
```

**Descripción:**
```
Resumen completo del mes con tus ingresos, gastos y balance total. Visualiza todas tus cuentas en un solo lugar y consulta tus últimos movimientos de forma rápida e intuitiva.
```

---

## 2. TRANSACCIONES

**Título:**
```
Registra tus Movimientos Fácilmente
```

**Descripción:**
```
Registra ingresos, gastos y transferencias entre cuentas en segundos. Organiza tus transacciones por categorías, añade notas y configura pagos recurrentes para automatizar tu control financiero.
```

---

## 3. CUENTAS

**Título:**
```
Gestiona Todas tus Cuentas
```

**Descripción:**
```
Administra cuentas bancarias, efectivo, tarjetas y wallets digitales en un solo lugar. Visualiza saldos actualizados, personaliza con colores e iconos, y mantén el control total de tu dinero.
```

---

## 4. METAS

**Título:**
```
Alcanza tus Objetivos Financieros
```

**Descripción:**
```
Establece metas de ahorro y sigue tu progreso en tiempo real. Visualiza cuánto has ahorrado, cuánto falta para alcanzar tu objetivo y celebra cada logro que te acerque a tus sueños.
```

---

## 5. PRESUPUESTOS

**Título:**
```
Controla tus Gastos con Presupuestos
```

**Descripción:**
```
Crea presupuestos mensuales, semanales o anuales por categoría. Monitorea cuánto has gastado, cuánto te queda disponible y recibe alertas cuando te acerques al límite. Mantén el control de tus finanzas.
```

---

## 6. PRÉSTAMOS

**Título:**
```
Administra tus Préstamos y Deudas
```

**Descripción:**
```
Registra y controla todos tus préstamos y deudas en un solo lugar. Haz seguimiento de pagos, tasas de interés, fechas de vencimiento y visualiza tu progreso hacia la libertad financiera.
```

---

## Notas para Google Play Console

- **Idioma:** Español
- **Formato de texto:** Mantener el formato con saltos de línea para mejor legibilidad
- **Límite de caracteres:** Las descripciones están optimizadas para mostrarse correctamente en la tienda
- **Keywords sugeridas:** Gestión financiera, ahorro, presupuesto, cuentas, transacciones, metas, préstamos, finanzas personales
